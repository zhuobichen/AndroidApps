# 卷灵 / JuanLing（原 VideoQuiz）

拍一段试卷录像，交给**你自己的电脑**解析，拿回答案和 PDF。

视频不出本地网络。手机只是遥控器和显示器，真正读题、解题、排版都在电脑上的 DSH 里跑。

---

## 它解决什么问题

早期版本是手机自己抽帧、逐帧调云端多模态模型。问题是：

- 整卷 40+ 题要把几十张图发给云端，慢且贵
- 上下文一长就得压缩，前后题容易串
- 模型不稳定，同一题两次答案可能不同

现在改成「电脑端跑一个完整会话」：会话能连续读完整段视频、保持题目编号一致、最后排版成 PDF，而且你可以**追问**它为什么这么解。

---

## 整体架构

```
┌─────────── 手机（本 App）───────────┐
│ 选视频 → 整段一次性上传（不分片）      │
│ 任务队列 / 历史 / 追问 / 内置 PDF 阅读 │
└──────────────┬──────────────────────┘
               │ HTTP + Bearer 令牌（局域网 / IPv6）
┌──────────────▼──────────────────────┐
│ 电脑：bridge/server.mjs（8665→8765） │
│  收视频落盘 → 投任务到指定会话         │
│  轮询任务状态 → 回传结果文件           │
└──────────────┬──────────────────────┘
               │ 本地回环 127.0.0.1:3080
┌──────────────▼──────────────────────┐
│ DSH（DeepSeek Harness）              │
│  会话里读视频 → 抽帧 → 逐帧读题        │
│  → 按题号合并 → 解题 → 写 PDF/TXT     │
└─────────────────────────────────────┘
```

桥接只监听局域网，`3080` / `9877` 从不对外暴露。

## 手机端功能

| 功能 | 说明 |
| --- | --- |
| 整段上传 | `setFixedLengthStreamingMode`，一次传完，不切片 |
| 目标会话 | 可选已有会话、自己命名新建、或每次上传新建一个 |
| 派发确认 | 默认上传后**不自动**派发，需点「开始处理」（可在设置里改成自动） |
| 任务队列 | 多任务并行查看，支持取消 / 重新派发 / 打开结果 / 追问 |
| 历史任务 | 最近 30 条，结果文件本地已有则复用，不重复下载 |
| 内置 PDF 阅读器 | 用 `android.graphics.pdf.PdfRenderer` 逐页渲染，不依赖第三方 App |
| 继续追问 | 独立对话页，追加到处理该任务的同一个会话，不重新生成 PDF |
| 断点恢复 | 退出 App 再进来会自动接上未完成的任务 |
| 状态识别 | 会话不在运行（且超过宽限）判为「已中断」，提示重派而不是永远转圈 |

### 为什么默认不自动派发

自动派发会在你还没确认时就把任务塞进会话，事后想改目标会话就晚了。
v2.2 起默认改成人工确认，勾选设置里的「上传后立即派发任务」可恢复自动。

## 电脑端

**必须单独部署**，只装 APK 用不了。完整步骤见 [bridge/README.md](bridge/README.md)：

| 需要 | 作用 |
| --- | --- |
| Node.js 20+ | 跑桥接 |
| DSH | 跑解题会话 |
| 插件 `@zhuobichen/dsh-agent-supervisor` | 会话列表 / 派发 / 追问 / 权限（**第三方，必须自己装**） |
| 桥接 `bridge/server.mjs` | 收视频、投任务、回传结果 |
| 一个工作区 | 限定投递范围，防投错项目 |

装完双击 `bridge/preflight.cmd` 自检，会逐项告诉你缺什么。

## 关键接口

除 `/api/health` 外都要 `Authorization: Bearer <token>`。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/jobs` | 上传整段视频（可带 `X-VideoQuiz-No-Dispatch: 1` 只存不发） |
| GET | `/api/jobs` | 任务列表（含状态与目标会话） |
| GET | `/api/jobs/:id/status` | 单任务状态 |
| POST | `/api/jobs/:id/forward?force=1` | 派发 / 强制重投 |
| POST | `/api/jobs/:id/cancel` · `/resume` | 取消 / 恢复 |
| GET | `/api/jobs/:id/result` | 结果文本 + 文件清单 |
| GET | `/api/jobs/:id/files/:name` | 下载结果文件 |
| GET/POST | `/api/jobs/:id/chat` | 追问：读最近消息 / 再发一条 |

### 任务状态

| 状态 | 含义 | 处理 |
| --- | --- | --- |
| `uploaded` | 已上传未派发 | 点「开始处理」 |
| `processing` | 已投给会话 | 等 |
| `complete` | 有结果 | 下载 |
| `stalled` | 会话没在跑，或超时无产出 | 「重新派发」 |
| `cancelled` | 已取消 | 「恢复」 |

`stalled` 判定：目标会话不在运行（超过 3 分钟启动宽限），或 45 分钟内没有任何文件变化。

## 已知限制

1. **debug 签名**，不能上架商店
2. 桥接是 DSH 的子进程，DSH 重启会一起退出（重新双击 `start.cmd`）
3. 电脑端不改默认权限的话，写文件时会逐次弹人工批准
4. 追问页只显示最近 40 条消息
5. 校园网/公共 WiFi 常做客户端隔离，IPv4 常不通，需用 IPv6
6. 结果文件存在 `Android/data/com.zhaowen.videoquiz/files/`，卸载即清除（可从电脑重新下载）
