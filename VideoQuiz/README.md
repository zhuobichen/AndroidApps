# VideoQuiz · 视频成卷

把一段"试卷录像"变成**题目 + 答案的 PDF**。

## 流程

```
选视频 → 抽帧(2fps) → 清晰度过滤 → 静止帧过滤（指纹相似度 > 0.995 丢弃）
      → 逐帧送多模态模型（JSON：原文 passage + 题目 questions）
      → 原文按段落去重（三元组 Jaccard ≥ 0.7 视为重复）、题目按题号合并
      → 按视频顺序排成「原文 → 题目」 → 解题 → 生成 A4 PDF（含参考答案）
```

## 实测（2026 全国一卷英语，28 秒录像）

| 指标 | 结果 |
|---|---|
| 视频 | 28.1s · 1280×720 · HEVC |
| 清晰帧 | 56（2fps × 28s） |
| 识别 | 30 条（含写作题与语法填空） |
| 解题 | 28/30 有答案 |
| PDF | 5 页，含题目页 + 参考答案页 |

## 接口

默认 DeepSeek（`https://api.deepseek.com`，模型 `deepseek-chat`，**支持读图**）。
设置里可改成任意 OpenAI 兼容服务。

## 已知限制

- 写作/语法填空也被当成题目（题号从 1 开始），可手动忽略
- PDF 只做了最简排版（没有分栏、题号缩进以外没有样式）
- 竖屏滚动拍摄效果好；斜拍/反光会明显掉识别率
